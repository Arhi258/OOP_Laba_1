
# Лабораторная работа № 1

**Дисциплина:** Объектно-ориентированное программирование

**Тема:** Модули и пакеты

**Вариант:** 5

## Описание

В данной лабораторной работе изучается работа
с модулями и пакетами языка Python.

Задание 1 — работа с замыканием функций.

Задание 2 — обработка списка авиарейсов
с использованием словарей.

Каждая функция размещена в отдельном пакете.

## Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

## Запуск программ

```bash
python -m Tasks.task_1.main
```

Задание 2:

```bash
python -m Tasks.task_2.main
```
